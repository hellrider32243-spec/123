# Полка — сайт магазина в Москве

Одностраничный сайт продуктового магазина с онлайн-заказами через Яндекс Маркет и Купер.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Что внутри

- Hero с брендом и призывом к онлайн-заказу
- Блок ассортимента
- Доставка: Яндекс Маркет, Купер, заказ по телефону
- Адрес и часы работы в Москве

Контакты и тексты правятся в `src/data.ts`.
